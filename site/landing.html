yolo-bridge by YOLO Studio

Your own agent,
in your cloud workspace.

yolo-bridge runs Claude Code or Codex on your machine and shows it in your YOLO Studio workspace as a tile, like any cloud agent. Prompts from the workspace land in the same session you keep driving locally.

curl -fsSL https://yolobridge.sh | sh

macOS and Linux. Needs Node.js 20 or newer; the script checks, and never uses sudo.

Read the script first

What happens when you run it

  1. The script installs yolo-bridge with npm.
  2. yolo-bridge login signs you in to YOLO Studio through a browser link.
  3. yolo-bridge attach lets you pick a workspace and starts your agent in this terminal.
  4. Your agent appears in the workspace as a tile, with the same workspace tools a cloud agent gets.

Nothing connects in to your machine: the bridge makes one outbound connection. It sends files only when you share them, or when your agent does from paths you allow. Your agent still runs as you, with your shell.

Rather run npm yourself? It is the same package:

npm install -g @yolo-labs/yolobridge

Then run yolo-bridge login and yolo-bridge attach. Pass --agent codex to attach Codex instead of Claude Code.
